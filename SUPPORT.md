# Support

## Ask a question

Open a blank issue and say what you tried. Name the client, the plugin and
their versions.

## Report a problem

Use the issue form that fits:

- **Install problem**: a plugin will not install, enable or load.
- **Bug**: a plugin loads but does the wrong thing.

Each form asks for the client, the plugin, their versions and the output you
saw.

Report a vulnerability privately, as [SECURITY.md](SECURITY.md) describes.
Never describe a vulnerability in a public issue.

## Report a client defect upstream

When a client fails the same way with every plugin, the defect is the
client's. Report it where that client tracks issues:

- Claude Code: <https://github.com/anthropics/claude-code/issues>
- Codex: <https://github.com/openai/codex/issues>
- Oh-My-Pi: <https://github.com/can1357/oh-my-pi/issues>
- Hermes: <https://github.com/NousResearch/hermes-agent/issues>
