# Methods cluster (05) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring the four reasoning packages (`design-review`, `cognitive-load`,
`toc-thinking`, `triz`) to the spec's manifest, skill and README norms, with their skills
renamed to `red-flags`, `extraneous`, `root-cause` and `contradiction`, and ARIZ-85C
split out of triz into a second skill, `ariz` (accepted by the owner).

**Architecture:** Each package is changed in two tasks, and triz in three: Task 4B
splits ARIZ-85C into its own skill. Task A renames the skill with
`git mv` and fixes its front matter, its reference table and its hand-offs. Task B
rewrites the manifest and the README together, then runs `bash tools/regenerate.sh` (plan 02),
which fills the README's `description` and `install` regions and rewrites the vendor
manifest copy and the catalogue. Plan 02 has already written each package's LICENSE and
the reference TOCs; `git mv` carries the TOCs to the new skill directory. A last task
verifies the whole cluster.

**Tech Stack:** Markdown, JSON, `jq`, `git`, `tools/regenerate.sh` (plan 02, which calls
`npx --yes doctoc@2.2.1`), `tools/check-conformance.py`, `claude plugin validate`
(Claude Code 2.1.278).

Spec: `../specs/2026-09-24-marketplace-quality-design.md` §4.1 (per-manifest part), §5.1,
§5.4, §10. Conventions: `2026-09-25-00-conventions.md` (binding). Review findings
covered: M5, M6, M7, L1, L3, L4 (`../handoff/2026-09-24-marketplace-quality/review/quality-review.md`).

## Split assessment (proposals for the owner, not tasks)

Spec §5.4 asks for every skill to be assessed for size and breadth. Nothing below is
executed before the owner approves it. Names follow the §5.4 rule: one word or one
compound, distinctive without the plugin prefix, never the plugin's name.

### triz: matrix route vs ARIZ — accepted by the owner, executed as Task 4B

- **Finding.** The skill held two methods with different triggers. Steps 1–8 are the
  short route. Step 9 is ARIZ-85C, a nine-part algorithm with its own 337-line reference
  that the short route never opens. A third of the front-matter description went to
  ARIZ, which diluted the trigger for the common case.
- **Result.** `contradiction` keeps Steps 1–8, `parameters.md`, `matrix.md`,
  `principles.md` and `sources.md`. `ariz` carries the ARIZ-85C walk and
  `ariz-85c.md`. `principles.md` and `sources.md` are shared: `ariz` names them by
  relative path, and nothing is duplicated. `contradiction` hands a problem the matrix
  did not crack to `ariz`, and `ariz` hands a restated technical contradiction back.

### toc-thinking: per tree — declined by the owner

The five tools form one sequence that the TOCICO Dictionary names as one (*change
question sequence*). Each tool's output is the next one's input, Step 1 routes between
entry points, and `clr.md` serves three of the five trees. The skill stays whole.

### design-review — no split

One procedure with one output, a ranked list of findings. Steps 3–6 are lenses of one
review, and Step 1's question router already lets a single question start at its step.
190 lines.

### cognitive-load — no split

One diagnosis procedure. Step 5 (published measures) is optional and ten lines long.
211 lines.

## Decisions from the plan review

1. **Source notes.** The five sentences in the references that say a title or an
   attribution "was not verified" keep their fact in other words ("not as read from the
   works", "no primary text read here confirms"). The §10 grep stays as it is.

   commits the regenerated files in a `chore:` commit right after its package commit
   (Steps 10–11 of Tasks 1B, 2B, 3B and 4C). Plan 06 starts from a clean diff.
3. **`root-cause` stays.** The name was closed in spec §8. The owner declined the
   toc-thinking split and accepted the triz split (Task 4B).
4. **Usage is a plain prompt**, as spec §5.1 says. No per-client command lines.
