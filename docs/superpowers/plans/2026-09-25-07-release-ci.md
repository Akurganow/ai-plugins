
- [ ] **Step 2: Run the Codex hook control in its own `CODEX_HOME`**

The control is a legacy-format plugin whose `hooks/hooks.json` Codex discovers by default (<https://developers.openai.com/plugins/build/plugins>, "Codex discovers `hooks/hooks.json` by default …"). If its marker never appears in `debug prompt-input`, that command runs no SessionStart hook at all. `CODEX_HOME` keeps the run out of the owner's configuration.

```bash
export CODEX_HOME="$RUN/codex-home"; mkdir -p "$CODEX_HOME"
ctl="$RUN/hook-control"
mkdir -p "$ctl/.claude-plugin" "$ctl/plugins/hook-control/.codex-plugin" "$ctl/plugins/hook-control/hooks"
printf '%s\n' '{"name":"hook-control","owner":{"name":"spike"},"plugins":[{"name":"hook-control","source":"./plugins/hook-control"}]}' > "$ctl/.claude-plugin/marketplace.json"
printf '%s\n' '{"name":"hook-control","version":"0.0.1","description":"Spike 5 control"}' > "$ctl/plugins/hook-control/.codex-plugin/plugin.json"
printf '%s\n' '{"hooks":{"SessionStart":[{"hooks":[{"type":"command","command":"echo HOOK-CONTROL-MARKER"}]}]}}' > "$ctl/plugins/hook-control/hooks/hooks.json"
{
  codex plugin marketplace add "$ctl" --json; echo "exit=$?"
  codex plugin add hook-control@hook-control --json; echo "exit=$?"
  codex debug prompt-input > "$RUN/control-no-bypass.json" 2>&1; echo "no-bypass exit=$?"
  codex --dangerously-bypass-hook-trust debug prompt-input > "$RUN/control.json" 2>&1; echo "bypass exit=$?"
  echo "marker count: $(grep -c HOOK-CONTROL-MARKER "$RUN/control.json")"
} 2>&1 | tee "$RUN/codex-control.txt"
unset CODEX_HOME
```

Read the result as one of three:

| Output | Meaning | What Task 5 does |
| :-- | :-- | :-- |
| `bypass exit=0`, marker count ≥ 1 | `debug prompt-input` runs SessionStart hooks | keeps the hook step as written, allowed to fail |
| `bypass exit=0`, marker count 0 | it runs no SessionStart hook | replaces the hook step with the "not run" notice (lead's decision) |
| `bypass exit` non-zero, and the output asks for a login | not answered locally | keeps the hook step as written; Task 7 reads the answer from the first run |

A flag error (`unexpected argument`) on the top-level `--dangerously-bypass-hook-trust` is a fourth case. Record it, then retry with `codex debug prompt-input -c` followed by the equivalent config key if `codex --help` names one. If it names none, treat the case as "not answered locally".
